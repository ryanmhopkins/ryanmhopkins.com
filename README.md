# ryanmhopkins.com

Personal homepage for ryan hopkins. Static HTML and CSS, served by GitHub Pages at the custom domain in `CNAME`.

## Edit

- Page copy and product links live in `index.html`.
- Styles live in `styles.css`.

## Run

Open `index.html` directly in a browser, or serve the folder with any simple static web server.

## Public page discovery

`robots.txt` points crawlers to `sitemap.xml`, which lists the homepage and the ClearFrame walkthrough. Both pages declare canonical URLs. Keep the sitemap limited to real public pages and update it when pages move. These files enable discovery but do not establish that a search engine has indexed a page or sent traffic.
